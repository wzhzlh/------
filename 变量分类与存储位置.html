01

变量分类与存储位置

四种变量各有不同的作用域 / 链接 / 生命周期，但最终都落在下面这张物理硬件模型里。点卡片，看它住在芯片的哪一块。

局部变量→ 栈 stack
作用域块 · 链接无 · 生命周期自动
全局变量→ .data
作用域文件 · 链接外部 · 生命周期静态
静态全局→ .bss
作用域文件 · 链接内部 · 生命周期静态
静态局部→ .bss
作用域块 · 链接无 · 生命周期静态

对应声明

// 全局：文件作用域 + 外部链接
int g = 10; // 已初始化 → .data
static int s; // 未初始化 → .bss
 
void f(void) {
  int a; // 局部 → 栈
  static int cnt = 0; // 静态局部 → .bss
}
点击上方卡片，右侧会告诉你：它存哪、为什么、怎么初始化。

三条铁律

1. 作用域是「编译期、关于名字」的，生命周期是「运行期、关于内存」的——两者可以不一致。
2. 存储上只有两大去处：栈（自动）或 静态区 .data/.bss（静态）。
3. 静态局部 = 作用域局部、生命周期全局——看不见，但一直活着。

上电 → 取 MSP → Reset_Handler → 拷贝 .data → 清零 .bss → 初始化栈 → main()

02

函数调用：分类结论如何在运行时兑现

先看上一节的分类，再看同一个函数连调 3 次：普通局部 a 在栈上重建又销毁；静态局部 cnt 在静态区 .bss 固定住址、跨调用累加。

待命点击「调用 f() 一次」，逐步验证局部变量与静态局部变量的生命周期。
void f(void) {
  int a = 0; // 栈：每次重建
  static int cnt = 0; // .bss：只初始化一次
  a++;
  cnt++;
}
调用a（局部/栈）cnt（静态/.bss）
尚未调用
SRAM · 栈区（自动生命周期，地址高→低）
SRAM · 静态区 .bss（静态生命周期，固定住址）

关键连接：作用域决定“名字在哪里可见”，生命周期决定“内存活多久”。静态局部仍只在块内可见，但它的存储位置和寿命与全局静态变量一致。
